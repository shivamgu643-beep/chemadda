Connect FileDrop to Google Drive

  1. Open Google Cloud Console and create a project.
  2. Under APIs & Services → Library, enable Google Drive API.
  3. Configure OAuth consent / Google Auth Platform. For personal testing, add your Google account as a test user if the app is in Testing mode.
  4. Create an OAuth Client ID of type Web application. Add this site's exact origin under Authorized JavaScript origins (for example, http://localhost:8000 or your GitHub Pages origin). No client secret is needed in this browser app.
  5. Paste the Client ID above and save it, then sign in.
  6. To publish free: upload this folder to a GitHub repository and enable GitHub Pages in Settings → Pages. Add the published site's origin to the OAuth client. Or test locally using python -m http.server 8000 and open http://localhost:8000.

Google can change its consent-screen rules. If public sharing is disabled by an account administrator, FileDrop cannot override that policy.

FileDrop is an independent demo, not a Google product. The site code does not contain your Google credentials. Shared files remain in your Google Drive.
